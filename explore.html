Time Series

Every canonical dataset in the pipeline: pick a category, product, and variable, then switch between time series and seasonal-cycle views. Anomalies are always relative to each product's own fixed calendar-month climatology — never a year-against-year comparison. For the interactive map, see the Home page; for the regional summary table and cross-product heatmaps, see Summary & Heatmaps.

Compare variables

Overlay standardized anomalies (σ) on one chart to see how variables move together over time. All series share one axis because σ removes each variable's own physical units, leaving only how far each one departs from its own baseline.
